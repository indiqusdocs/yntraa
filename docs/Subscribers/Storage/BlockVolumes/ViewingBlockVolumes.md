# Viewing Block Volumes

Viewing block volumes allows you to monitor and manage the additional storage attached to your cloud instances. In Yntraa Cloud, you can view key details such as volume name, attached instance, and storage utilization to track disk usage, optimize resource management, and maintain better control over your cloud infrastructure.

To view data or root disks, follow the step:

Navigate to **Storage > Block Volumes.** The following screen appears:
