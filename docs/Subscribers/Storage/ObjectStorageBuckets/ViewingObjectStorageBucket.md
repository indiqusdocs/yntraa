# Viewing Object Storage Bucket

Viewing object storage bucket shows all the object storage buckets in your cloud environment. Each bucket is listed with key information, including the cluster name, number of objects, storage Size, and creation time, allowing you to quickly review its status and usage.

To view an object storage bucket, follow the step:

Navigate to **Storage > Object Storage Buckets**. The following screen appears:
