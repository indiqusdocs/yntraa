# Feature List and Integration Details

The feature list and integration details section provides an overview of the core capabilities and integration aspects of the Object Storage service. It outlines the standard and service-specific integration touchpoints that enable seamless provisioning, management, and monitoring of storage resources. 

Additionally, it highlights the key features available within the service, helping you understand its functionality and effectively manage their object storage environment.

This section comprises of the following sub-sections:

## Standard Integration Touchpoints

The following standard integration touchpoints describe the key integration points that enable the provisioning, management, and monitoring of Object Storage services within the Yntraa Cloud platform:

- **Account Creation:** When you opt for the Yntraa Storage, an account is created on object storage platform. This account allows you to manage and configure your object storage platform deployment, access administrative features, and control various aspects of their storage environment.
- **Cataloguing:** This service is part of the catalogue, i.e., the service provider configures from where to deliver the service and what price to deliver the service.
- **Usage Reporting:** All usage data is available through the UI. You can log in to Yntraa Cloud at any time to view consumed resources and the associated usage details.

## Specific Integration Touchpoints

The following specific integration touchpoints define the core interactions that enable you to provision, manage, and access Object Storage resources through the Yntraa Cloud platform:

- **Create Buckets:** You can create buckets with unique names, following the naming convention mentioned on Yntraa Cloud.
- **Add Objects:** You can add objects to your respective buckets using the Yntraa Cloud.
- **Manage Service on Object Storage Platform:** Detailed object and bucket management is done via the object storage platform admin panel, which can be accessed directly from Yntraa Cloud.

## Feature List

The following feature List highlights the key capabilities of the Yntraa Object Storage service. These features enable you to create, manage, and access object storage resources through the Yntraa Cloud platform while ensuring compatibility, ease of use, and efficient storage management:

- **Single S3 Zone:** Currently, on Yntraa Cloud, only single S3 zone support is available.
- **Buckets View:** On the Yntraa Cloud UI, you can log in and view all the distinct buckets they have created.
- **Bucket Creation:** You can create buckets with unique names following the naming convention which is mentioned on the Yntraa Cloud UI.
- **Bucket Edit:** You can edit the already created Buckets at any point in time by logging in to the Yntraa Cloud UI.
- **Object Creation:** You can directly upload objects from the Yntraa Cloud console.
- **Object Deletion:** You can delete the objects associated with the bucket straightforwardly and hassle-free.
- **Object Access:** There is a Manage service button on the UI; to open a new tab, click on it with Object Storage Platform URL, and you can log in with your username and password, and simply they can access, manage and configure things related to their storage environment.
- **S3 API Compatibility:** Yntraa Object Storage Service is fully compatible with S3 API.
- **Option to Unsubscribe from the Service:** You can easily unsubscribe from the service at any time from the Yntraa Cloud UI only.
