# Managing NAT Gateways

Manage NAT gateways to monitor their status, review associated instances, manage IP addresses, and perform administrative operations such as restarting or deleting a gateway. These tasks help you maintain connectivity, ensure proper network configuration, and efficiently manage NAT gateway resources within your cloud environment.

To manage a NAT gateway, follow these steps:

1. Navigate to **Network and Security > NAT Gateways**.
   ![natgatewaydeploy](imgnew/natgatewaydeploy.png)
2. Click your created NAT Gateway from the list. The following screen appears:
   ![natdetails](imgnew/natdetails.png)

The NAT Gateway details are displayed under the following categories:
