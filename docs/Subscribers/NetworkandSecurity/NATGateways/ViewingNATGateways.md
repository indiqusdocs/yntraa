# Viewing NAT Gateways

The viewing NAT Gateways section provides an overview of all created NAT Gateways within the system. You can view the list of NAT Gateways along with their relevant details, enabling easy monitoring and management of configured network connectivity resources.

To view the NAT Gateways, follow the step:

Navigate to **Network and Security > NAT Gateways**. The following screen appears:
![NAT Gateways](imgnew/natgatewayinstances.png)
