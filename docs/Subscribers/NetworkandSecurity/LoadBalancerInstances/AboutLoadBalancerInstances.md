# About Load Balancer Instances

The Yntraa Load Balancer Instances (LBI) Service allows you to create load balancer appliances, which are Linux Instances pre-loaded with a [Alteon Control Panel]([Alteon Standalone with Azure LB](https://support.radware.com/app/answers/answer_view/a_id/1051429/~/alteon-standalone-with-azure-lb)) image. LBI can be used with VPC networks to achieve various traffic management features that are not possible using the standard VPC-based load balancing.

The following management features are supported on Yntraa Cloud:

- [Creating Load Balancer Instance inside a VPC](CreatingaLoadBalancerInstance.md)
- [Activating the Alteon Control Panel](ActivatingtheAlteonLBIControlPanel.md)
