# About Kubernetes

Yntraa Cloud provides users the ability to deploy highly-available Kubernetes clusters for their cloud-native development, deployment and DevOps use cases. The Yntraa Cloud Kubernetes Service extends basic and advanced cluster management functionalities via the cloud console UI and the `kubectl` utility. 

The following sections outline the process to provision, configure, and manage Kubernetes clusters using Yntraa Kubernetes Service on the Yntraa Cloud.
