# Viewing Kubernetes Cluster

View the Kubernetes cluster to monitor its configuration, status, and key details. Reviewing the cluster information helps you verify the deployment, check resource health, and access essential configuration details required for managing containerized workloads.

To view the kubernete cluster, follow these steps:

1. Navigate to **Compute > Managed Kubernetes**. The following screen appears: 
   ![Kubernetes List](img/kuberneteslist.png) 
2. Click on your created kubernete cluster from the list. The Overview tab opens automatically. The following screen appears with the details: 
   ![Overview](img/kubernetesoverview.png)
