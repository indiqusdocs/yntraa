# Overview

To view the additional details the below details, select a Kubernetes cluster, and access the **Overview** tab.![Kubernetes Overview](img/kubernetesoverview.png)
The following details are shown:
- [Configuration and Availability](#configuration-and-availability)
- [Nodes](#nodes-information)
- [Internal Information](#internal-information)

## Configuration and Availability

1. The cluster’s status, **RUNNING**, is displayed in Green, whereas **STOPPED** is displayed in <span style={{ color: 'red' }}>red</span>.
2. Information about the VPC networking zone
## Nodes Information 

This displays the basic information about the nodes as listed below:

- Cluster Size
- Computed Pack
- Root disk size
## Internal Information

This displays the information used for internal identification of this Cluster and communication with other internal services.

- Kubernetes Version
- Virtual router internal name
- Created on
