# Viewing RHEL Instances

The windows instances page lets you view and monitor all RHEL virtual machines in your cloud environment. It displays key instance details and status information, helping you quickly identify, access, and manage your RHEL-based workloads.

To view the RHEL instances, follow the step: 

1. Navigate to **Compute > RHEL Instances**.
