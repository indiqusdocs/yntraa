# Introduction
We are excited to announce the general availability of Yntraa Cloud Platform, a modern cloud infrastructure platform designed to support enterprise applications, data platforms, and digital services.

This first release introduces a comprehensive set of foundational cloud services that enable organizations to provision, manage, and scale infrastructure resources on demand. The platform combines network and security, compute, storage, tools and utilities, and other core services into a unified environment, allowing teams to deploy workloads with greater flexibility, performance, and control.

## Services Available in this Release

### Network and Security Services
Secure and manage cloud workloads with integrated networking and security services.

Key capabilities:
- Virtual private networks (VPCs)
- Subnet configuration and IP management
- Load balancing for application traffic
- Secure connectivity between cloud services

### Compute Services
Provision and manage virtual compute resources to run applications and services.

Key capabilities:
- Virtual machine provisioning
- Flexible CPU and memory configurations
- Rapid instance deployment
- Lifecycle management for compute resources
- Managed Compute

### Storage Services
Store and manage data using scalable and highly available storage services.

Key capabilities:
- Block Volumes for compute workloads
- Object storage for unstructured data
- Persistent storage volumes
- Scalable storage capacity

### A Gist of the Services
Access a comprehensive suite of cloud services to build, manage, and secure applications and infrastructure.

Key capabilities:
- Compute
- Managed Database as a Service
- Storage as a Service
- Backup and Recovery Service
- DevOps as a Service
- Messaging Services
